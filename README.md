# Парсер объявлений Avito

Этот скрипт на Python использует Playwright для парсинга объявлений с Avito по заданным артикулам. Он собирает информацию о 5 самых дешевых объявлениях для каждого артикула, соответствующих определенным критериям, и сохраняет результаты в CSV-файл.

## Особенности

- **Поиск по списку**: Считывает артикулы для поиска из файла `queries.txt`.
- **Гибкая настройка**: Параметры поиска (регион, состояние товара, сортировка) настраиваются в константах скрипта.
- **Фильтрация**: Отбирает объявления только в новом состоянии из Москвы и Московской области.
- **Исключение своих**: Не включает в выборку объявления от продавца HNX AUTO.
- **Обработка ошибок**: Корректно обрабатывает случаи, когда объявления не найдены или доступ к сайту ограничен.
- **Локальный кеш**: Может работать с локально сохраненными JSON-файлами для отладки без реальных запросов к сайту.
- **Запуск в Docker**: Полностью настроен для запуска в изолированном Docker-контейнере.

## Конфигурация

Основные параметры поиска задаются в файле `parser.py`:

- **`QUERIES_FILE`**: Файл, содержащий список артикулов для поиска (каждый артикул с новой строки). По умолчанию: `queries.txt`.
- **`LOCATIONS_FILE`**: Файл с идентификаторами регионов для фильтрации. По умолчанию: `slocations.json`.
- **`SEARCH_PARAMS`**: Словарь с параметрами для API-запроса Avito.
  - `params[110056]` и `s`: Состояние товара (`418153` и `1` - новое).
  - `params[167128]` и `sortDefault`: Сортировка (`3270783` и `1` - по возрастанию цены).
  - `locationId`: ID региона (`107620` - Москва и МО).
  - `categoryId`: ID категории (`10` - Главная/Транспорт/Запчасти и аксессуары).
- **`MAX_ITEMS_PER_ARTICLE`**: Максимальное количество объявлений для сохранения по каждому артикулу.
- **`OUTPUT_CSV_FILE`**: Имя итогового CSV-файла. По умолчанию: `result.csv`.

## Установка и запуск

### Вариант 1. Запуск через Docker

**Требования:**

- Docker
- Docker Compose

**Шаги:**

1. **Соберите и запустите контейнер:**
    Находясь в корневой директории проекта, выполните команду:

    ```bash
    docker-compose up --build
    ```

### Вариант 2. Локальный запуск

**Требования:**

- Python 3.10+
- Pip

**Шаги:**

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/obutrimov/test-av-hnx
    cd <директория с клонированным репозиторием>
    ```

2. **Создайте и активируйте виртуальное окружение:**

    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    # venv\Scripts\activate    # Для Windows
    ```

3. **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```

4. **Установите браузеры для Playwright:**

    ```bash
    playwright install chromium
    ```

5. **Запустите парсер:**

    ```bash
    python parser.py
    ```

## Результат

После выполнения скрипта в корневой директории будет создан файл `result.csv` с результатами парсинга.
